# 面板怎么写：一个只读的「仪表盘 + 设置页」

面板**不是必需品**，但一旦你的 bot 跑起来了，它会变成最重要的调试工具——
因为你能一眼看到「她现在是困还是饿、好感多少、今天花了几块钱、服务有没有死」。

本仓库**不提供面板源码**，只给结构与写法。原因：
面板一定是高度私人化的（放什么、叫什么、对谁开放），而且它天然会碰敏感数据。
给你一份能跑的整包，反而会让你把「不该公开的东西」也一起带走。

---

## 1. 它本质上就是两样东西

| 半边 | 跑在哪 | 干什么 |
|---|---|---|
| **宿主半** | 宿主进程内（插件） | 注册 HTTP 路由：读状态 JSON、写设置、暴露工具 |
| **浏览器半** | 设置页里的一个视图 | 拉路由、渲染卡片、提交修改（自带登录态，不用自己写鉴权） |

一个最小的宿主插件大概是这样：

```js
// index.js —— 宿主半
export function apply(ctx) {
  ctx.server.get('/api/awaken/status', async (req, res) => {
    const growth = readJson(DATA_DIR + '/养成.json')   // 只读，不改
    res.json({ ok: true, stats: growth.stats })
  })

  ctx.server.post('/api/awaken/settings', async (req, res) => {
    // 写之前先校验：类型、范围、权限
    const { sleepiness } = req.body ?? {}
    if (typeof sleepiness !== 'number') return res.status(400).json({ ok: false, error: 'bad input' })
    updateJson(DATA_DIR + '/养成.json', (g) => { g.stats.sleepiness = clamp(sleepiness) })
    res.json({ ok: true })
  })
}
```

浏览器半就是一个普通的前端视图：`fetch` 上面这些路由、渲染、提交。

## 2. 建议的页面（按价值排序）

1. **状态**——红绿灯：WS 通不通、侧车活没活、守护跑没跑、数据文件多久没更新
2. **养成**——饱足/清洁/体力/睡意/情绪/健康/体重，带涨落说明
3. **印象**——每个人的好感、档位、最近说过什么
4. **日记**——最近 7 天，按天折叠
5. **用量**——近 7 天请求数、缓存命中率、每天花费
6. **设置**——场景开关、人设指针、轮换阈值

**为什么第一页是「状态」**：你 90% 的「她怎么不说话了」都是服务挂了，不是模型抽风。
把「服务活着吗」做成第一屏，能省掉大量瞎猜。

---

## 3. 路由设计的三条规矩

1. **读接口只读**：`GET` 绝不写盘。否则你刷新页面就把状态改了。
2. **写接口必须校验**：类型、范围、权限（只认 `OWNER_QQ`）。
3. **失败要回可读的话**：`{ ok:false, error:'...' }` + 4xx，而不是 500 加一段栈。

---

## 4. 数据文件结构（和侧车共用）

```
data/
  养成.json        数值（饱足/清洁/体力/睡意/情绪/健康/体重）
  印象.json        好感、档位、最近互动
  激素.json        四条激素 + 历史峰值
  日记状态.json     上次写日记的时间
  用量.json        每日请求数、token、花费
  主动草稿.json     主动消息的草稿与冷却
```

**建议**：面板只读这些 JSON，所有修改走路由。这样「文件格式」只有一处权威，不会两边漂。

---

## 5. 鉴权：别自己造

面板挂在宿主 Web 端口下，**自动继承宿主登录态**。
所以：命令行 `curl` 一律 401 是**正常的**，不是坏了。

要验证面板，要么用浏览器（已登录），要么写一个 standalone 脚本复刻「读 JSON」的逻辑——
这也是我更常用的调试方式：**不依赖面板也能看到数据**。

---

## 6. 一个坑

面板前端是**打包产物**。改完 `client.js` 不重开宿主，页面不会变。
- 改数据文件 → 刷新页面即可
- 改前端代码 → 完全退出并重开宿主

---

## 7. 如果你只想做一个最小版

就做两页：**状态** + **养成**。
一页告诉你「服务活着吗」，一页告诉你「她此刻怎样」。
其余都可以用 `read` 文件代替。
