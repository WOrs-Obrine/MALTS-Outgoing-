# 04 · 踩过的坑（按惨烈程度排序）

每条都是真事，写清楚**现象 → 根因 → 修法**。照着避开能省你几个通宵。

## 1. 补丁被「守护」悄悄回滚（最阴）

**现象**：明明改好的代码，过几分钟行为变回旧版；日志没报错。
**根因**：守护脚本每 5 分钟比对文件哈希，`hash.json` 里 `patched` 字段是**几天前的旧值** → 它认为「文件被改坏了」→ 拿快照盖回去。
**修法**：哈希表只用来判断「是否被重装回原版」——即 `当前哈希 === base` 才盖快照，否则只记 `unknown` 并 log。改完代码要**同时**更新 `hash.json` 与快照。

## 2. 插件代码不热加载

**现象**：改了 `lib/*.js`，重启侧车/刷新面板都没用，行为一点没变。
**根因**：插件在宿主启动时加载一次；`cordis.patch.yml` 也是启动时读。
**修法**：每次改插件代码或配置 → **重启 DSH Desktop**，然后看日志 `bridge ready`。人设 md 例外（每回合现读，即时生效）。

## 3. `defineTool` 漏 `output.render` → 整个群哑掉

**现象**：群消息能被「叫到」，日志紧跟着 `agent create failed (Cannot read properties of undefined (reading 'render'))`，然后一个字都发不出；私聊老会话正常。
**根因**：某工具注册时少了 `output: { schema, render }`，注册阶段抛错，这个群的 agent 建不起来。
**修法**：每个工具都给 `output`；改完用「shim 版 dsh-tools（缺 output 就 throw）」离线跑一遍 `registerTools`，能提前抓到。

## 4. 插件升级把补丁冲没了

**现象**：重启报 `TypeError: z.number(...).int is not a function`（本地配置用了 schemastery 不存在的 `.int()`）→ 启动失败 → 桌面端 plugin recovery **自动升级到上游新版** → 补丁全失效。
**修法**：数值用 `.step(1)`；把插件**钉死版本**（junction 指向固定生成目录）；升级前先备份 `lib/`；升级后逐条重打。

## 5. 中文 PowerShell 脚本解析炸

**现象**：`表达式或语句中包含意外的标记“}”`，但 `ParseFile` 有时报 0 错。
**根因**：文件是 UTF-8 **无 BOM**，Windows PowerShell 5.1 按 ANSI 解析中文注释，把结构搞乱。
**修法**：所有含中文的 `.ps1` 一律存 **UTF-8 带 BOM + CRLF**。改完重新转一次（编辑器保存常常又变回无 BOM）。

## 6. JSON 文件带 BOM

**现象**：`JSON.parse` 报 `Unexpected token \uFEFF`。
**修法**：读之前 `text.replace(/^\uFEFF/, '')`，写回时不要 BOM。

## 7. 侧车跑了两个实例

**现象**：好感涨两倍、主动消息发两条、日志时间线错乱。
**根因**：桌面端重启后旧进程没死，watchdog 又拉起一个。
**修法**：单实例锁（`pid` 文件/命名互斥），或拉起前遍历进程按命令行匹配脚本名并杀重复；面板/日志里显示当前 pid。

## 8. 静默丢消息

**现象**：会话日志里明明生成了回复，对方却没收到，也没有报错。
**根因**：`send_msg` 一次失败就抛，外层 catch 只记了一行。
**修法**：发送失败等 400ms 重试一次，仍失败写审计（含 chatId、长度、错误），并在面板上暴露「最近发送失败」。

## 9. 数值只涨不落 / 永不衰减（自锁）

**现象**：数值一路顶到 100 掉不下来。
**根因**：判定「在戏里」用了**结果**（如高潮度 ≥40），而高潮度高本身就是「在戏里」的表现 → 只涨不落。
**修法**：`在戏 = 开关 || (now - lastTouch < 10~15min)`，`lastTouch` 只由真实互动时间戳决定。

## 10. 「2 小时无接触归零」永不触发

**根因**：兜底用了 `updatedAt`（每次写盘都刷新），不是真正「上次接触」时间。
**修法**：单独存 `climaxAt` / `arousalAt` / `noteAt` / `cavityAt`，只在该字段变化时刷新。

## 11. 面板保存把时间戳抹了

**根因**：保存时用 `const it = {}` 整体替换 intimate 对象，`noteAt/climaxAt` 全丢；再无条件刷新 `climaxAt`，等于「保存任何字段都算刚接触」。
**修法**：`const it = { ...(旧对象), 新字段 }`，时间戳只在值变化时更新。

## 12. edge-tts 403 / venv 起不来

**现象**：语音是又尖又机械的 Windows SAPI 音。
**根因**：①旧版 edge-tts 被微软封（`WSServerHandshakeError: 403`）②`uv` 造的 venv 启动器坏了（`uv trampoline failed to spawn Python child process … os error 2`）→ 静默退回 SAPI。
**修法**：edge-tts 升到 7.x；容器里干净重建 venv（pypi 慢就换清华镜像）；代码里候选 python 路径列表逐个试探。

## 13. 群聊不回 ≠ bug

`requireMention` 默认开着：不 @、不叫名字，她就不说话（省 token 也防刷屏）。要让她主动接话，得单独做「兴趣点 + 上下文注入」。

## 14. 主动插话没上下文 → 必出糗

只给她「@她 + 对方那半句」，她只能靠猜。**必须**注入：群名 + 最近 5 句（谁说的、说了啥）+「接着最后一句自然接」。

## 15. 「我刚换了上下文」被她说出口

**根因**：上下文轮换提示写成普通内容，模型当台词了。
**修法**：明确标注「这是系统通知，不要复述，不要对对方提」。

## 16. 模板字符串里的 `\n` 被写成真换行

**现象**：`SyntaxError: Invalid or unexpected token`。
**修法**：在 JS 字符串里写 `\n`，别在编辑时敲成真实回车；改完必跑 `node --check`。

## 17. 路由路径转义写错

**现象**：面板接口一直返回空/读不到文件。
**根因**：`'D:\\DS\\...'` 写成四层反斜杠（`'D:\\\\DS\\\\...'`），实际解析成双反斜杠。
**修法**：路径统一用 `path.join()`，别靠手写转义。

## 18. 校验清单（改完必须过）

```text
node --check 每个改过的 .js/.mjs
重启宿主 → 日志 bridge ready / 无 agent create failed
一个工具数（注册数量）对不对
私聊 / 群里 @ 各一句
侧车 pid 只有一个
开关状态文件符合预期
```
