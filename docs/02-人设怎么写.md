# 02 · 人设怎么写：分层，然后只说该说的话

人设是唯一「每回合都注入」的东西，所以它决定她的**稳定感**。
写坏了的表现很典型：说两句就跑偏、每轮一个腔调、被骂了还在撒娇、私聊里像客服。

---

## 1. 先理解钱：为什么必须分层

一次请求的输入 token 分两种价：

| 类型 | 含义 | 价格（相对） |
|---|---|---|
| **命中缓存（hit）** | 前缀和上一轮一模一样 | 0.02 / 百万 token |
| **未命中（miss）** | 新内容，模型得从头读 | 1 / 百万 token |

**差 50 倍。** 所以：

- 你放在**系统提示**里的东西（会话一建立就固定，之后每轮都一样）→ 按缓存价，几乎免费；
- 你放在**每回合 user message** 里的东西（每轮都在变）→ 按未命中价，字字要钱。

我的第一版人设是整段塞进 user message 的：每回合 14K 字，一天 ¥6.95。
拆成「系统提示常驻 10K 字 + 每回合补 1.8K 字」之后，掉到 ¥2.5~3.5。

**结论：人设必须分两层，这不是优化，是能不能长期挂的前提。**

---

## 2. 两层怎么分

```
人设文件
├─ <!-- 核心:开始 --> … <!-- 核心:结束 -->   系统提示（会话创建时注入一次，之后吃缓存）
└─ <!-- 尾部:开始 --> … <!-- 尾部:结束 -->   每回合补到消息最前面（按未命中价）
```

**核心段放**：身份、自称、说话方式、情绪反应、边界、安全规则、场景开关、数值怎么读。
**尾部放**：最贴脸的几句性格核心——「你是谁」「几个面」「怎么称呼」「怎么说话」。
**其余全部不注入**：写成长尾（语料），需要时让她 `read` 一节。

代码上就是两个正则：插件从人设文件里抠出这两段，核心段注册成系统提示的一个 section，尾部段拼进每回合消息。
（`buildPersonaSystemText()` / `buildPersonaTailBlock()`，见 05。）

**为什么尾部只留 1~2K 字**：它是每回合都要重新付费的部分，也是「贴脸感」的来源。
我的实践是：性格骨架放尾部，长规则放核心，语料放文件。

---

## 3. 核心段该有什么

1. **身份与自称**：名字、物种/身份、怎么称呼对方
2. **说话方式**：句长、语气词、标点习惯、用不用引号
   - 我的设定是「平时不用引号，动作用（）包住」——一条规则，省掉一堆解释
3. **情绪与反应**：被夸 / 被怼 / 被冷落，分别怎么表现
4. **边界**：什么不做、怎么拒绝（硬拒会破坏沉浸，试试「凶一句再软」）
5. **安全规则**：见 03 最后一节，建议照抄
6. **场景开关**：怎么进、进去之后行为差在哪
7. **数值怎么读**：把「状态 → 语气」写成可执行的分档（见第 5 节）

---

## 4. 语气三条铁律（踩出来的）

- **反差**：平时懒散毒舌，认真时突然认真 → 比一直甜或一直凶都像人。
- **短句优先**：一句能说完就别两句；长段落只在情绪上来时出现。
- **不复读**：同一个口头禅、同一种句式别连着两轮用。

这三条要写成人设里的**规则**，不能只写在文档里——模型看不到文档。

---

## 5. 把数值接进人设：写成分档，不写形容词

反例：「你要根据心情调整语气」——模型会自由发挥，等于没写。
正例：

```markdown
- 心情 <20：不想说话，回答压到一两个字，被问才答
- 心情 20~50：正常，话短，带刺
- 心情 >50：话变多，会主动接梗
- 睡意 >80：说话含糊、断句、打哈欠；<20 但时间很晚 = 她最精神的时候
```

**为什么分档有效**：模型擅长「按条件选行为」，不擅长「把握程度」。给它阈值，它就在阈值之间稳定输出。

---

## 6. 语料分层表

| 类型 | 什么时候用 | 做法 |
|---|---|---|
| 身体/外观设定 | 被问、换衣、写动作前 | 单独 md，人设里留一行指针 |
| 关系/人物卡 | 遇到具体的人 | 一人一文件，按需读当前说话人那份 |
| 场景语料 | 触发对应场景 | 单独 md，按章节 `read`，一次一节 |
| 口头禅样本 | 平时说话 | 3~5 条写进尾部，多了会复读 |

**教训**：语料整段塞进人设 → 她会在不该用的时候也用，而且每回合都花钱。

---

## 7. 常见坏味道

- 写满「不要 AI 味」「要自然」——**没有可操作规则**，等于没写
- 一次改十处 → 出问题不知道哪条起作用；**一次改一处，聊三轮再看**
- 只写「她是什么」，不写「她怎么说话」——语气规则才是灵魂
- 把所有设定塞进核心段 → 每回合几万 token，钱包先死
- 忘了写「她不知道什么」——不写禁区，她会自己编设定，而且编得挺像

---

## 8. 我的文件清单（简化版）

```
提示词库/
  我的鱼.md          核心段 + 尾部 + 长尾（每回合现读）
  设定-躯体.md        身体细节（按需 read）
  语料-来历.md        她从哪来（被问起过往时 read）
  语料-场景.md        场景用词（按需 read）
  绑定.json          哪个会话用哪份人设
```

`绑定.json` 的价值：不同聊天（群 / 不同私聊）可以挂不同人设——群里一套收敛的，私聊一套松弛的。
