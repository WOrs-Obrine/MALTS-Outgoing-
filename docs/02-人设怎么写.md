# 02 · 人设怎么写

人设是唯一「每回合都注入」的东西，所以它决定她的**稳定感**。写坏了会出现：说两句话就跑偏、每次都一个腔调、被骂了还在撒娇、私聊里像客服。

## 分层：核心段 + 长尾

```
人设文件
├─ <!-- 核心:开始 --> … <!-- 核心:结束 -->   每回合必注入（3~6K 字符以内）
└─ 长尾（其余部分）                            模型需要时才 read
```

- **核心段**放：身份、自称、语气、说话方式、边界、场景开关、安全规则
- **长尾**放：性癖细节、语料、身体设定、妈妈/骂人/敏感点这类「按需查阅」的文件
- 语料**不要**塞进人设正文：用到时让她 `read`，或者做成工具（`malts_sensitive` 之类）按需读

好处：token 稳、改语料不动人设、语料膨胀也不影响每回合成本。

## 核心段该有什么

1. **身份与自称**：名字、物种/身份、怎么称呼对方（主人/你/名字）
2. **说话方式**：句子长短、语气词、标点习惯、是否用引号
   - 我们最后定的是：**平时说话不用引号，动作用（）包住**；只有跑团模式才 `“台词”` + `#` 动作
3. **情绪与反应**：被夸/被怼/被冷落分别怎么表现，别每次都「笑死」
4. **边界**：什么不做、什么要拒绝、怎么拒绝（生硬拒绝会破坏沉浸，建议「凶一句再软」）
5. **安全规则**（照抄都行，见 `docs/03-功能清单.md` 最后一节）
6. **场景开关**：侍寝/跑团/赛博精神病/当妈，各自的进入口令与行为差异
7. **数值感知**：她怎么读自己的养成数值、怎么按档位调整露骨程度

## 语气三条铁律（经验）

- **反差**：平时懒散毒舌，认真时突然认真 → 比一直甜或一直凶都像人
- **短句优先**：一句话能说完就别两句；长段落只在情绪上来时出现
- **不复读**：同一个口头禅/同一种句式别连续两轮用，写进人设的「防复读」条

## 语料分层（按按需读取设计）

| 类型 | 什么时候用 | 做法 |
| --- | --- | --- |
| 场景语料（高潮/敏感点/侮辱/妈妈） | 触发对应场景 | 单独 md，让她 `read` 或做成工具 |
| 身体设定（三围/穿着/小动作） | 被问、换衣、写身体前 | 单独 md，人设里留一行指针 |
| 性癖清单 | 判定她主动想不想 | 做成 JSON + 等级，别写进 prompt |
| 口头禅/句式样本 | 平时说话 | 少量写进核心段（3~5 条，多了会复读） |

**教训**：语料整段塞进人设 → 她会在不该用的时候也用，而且每回合都花钱。

## 数值与档位怎么接进人设

把「怎么读数值」写成规则，而不是让模型自由发挥：

```markdown
- 放纵档由「淫荡值 45% + 大胆值 35% + 高潮度 20%」算出来：<25 收敛 / 25-40 轻 / 40-55 中 / 55-68 重 / ≥68 最重
- 兴奋度 >30 时，叫声里会夹带「哦齁」系的音；越高越密；≥80 才失控
- 轻互动只 +1~4，前戏 +5~15，插入 +10~20，到顶 +20 封顶
```

写成可执行的分档，比「你要淫荡一点」有效一百倍。

## 常见坏味道

- 人设里写满「不要 AI 味」「要自然」——**没有可操作规则**，模型还是老样子
- 一次改十处 → 出问题不知道哪条起了作用；**一次改一处，聊三轮再看**
- 只写「她是什么」，不写「她怎么说话」——语气规则才是灵魂
- 把所有设定都塞进核心段 → 每回合 3 万 token，钱包先死

## 我的文件清单（简化版）

```
人设/
  我的鱼.md            核心段 + 长尾指针（每回合现读）

  语料-哄人.md          哄人方言（按需 read）
```
