# MALTS · 养一只 QQ 鲸鱼娘

这是一份「让 AI 在 QQ 里长期活着」的搭建记录与经验包，脱胎自我自己的 bot **麦芽汁**。
目标很朴素：**你少踩坑**。里面的人设骨架、补丁思路、面板描述、踩坑清单都可以直接抄，改成你自己的鱼。

> 说明：本仓库是**简化版**——只有人设骨架、搭建文档、功能清单和坑位记录。
> 不含我的私人语料、QQ 号、群号、本机路径和运行配置，那些请你自己写。
> 适用于成年人的私人陪伴/聊天场景，请遵守平台规则和当地法律。

## 她是什么

一台常开的 Windows 机器上，四块东西拼起来：

| 层 | 干什么 | 本仓库给什么 |
| --- | --- | --- |
| **宿主** DeepSeek Harness Desktop | 提供 agent 运行时、工具（读写文件/终端/联网）、上下文轮换 | 文档（自行安装） |
| **通道** `dsh-onebot-qq` 插件 | 连 NapCat/OneBot，收发 QQ 消息、群聊/私聊路由、工具注册 | 功能清单 + 补丁思路 |
| **人设** Markdown | 每回合现读的人格/语气/边界/场景开关 | 两份可直接用的人设骨架 |
| **旁听侧车** 本地 Node 进程 | 0 token 本地算印象、好感、激素、催主动消息、写状态卡 | 文档（自行实现，逻辑全写清了） |
| **面板**（可选） | 浏览器里调养成数值、看激素/日记/用量 | 功能说明 |

关键设计：**只有「对话」花 token**。旁听、算分、写状态、定时唤醒、刷空间这些全部在本地进程里做完，所以一天挂 24 小时，成本也只跟聊了多少有关。

## 能力概览（详细见 `docs/03-功能清单.md`）

- 群里/私聊自然接话：@ 或叫名字才回，私聊直回；分段发送、失败重试
- 长期记忆三层：热记忆（当前状态 + 每会话交接）、温记忆（人物/约定/日记）、冷记忆（工程台账）
- 上下文轮换：回合数 / token / 小时三阈值，交接只写指针不写全文
- 印象系统：好感、熟悉度、档位（路人/熟人/好感/特别关注），影响谁能跟她玩什么
- 激素：多巴胺/催产素/皮质醇/血清素，按事件推、按半衰期落
- 养成数值：饱食/清洁/体力/睡意/兴奋度/淫荡/大胆/高潮 + 体重、癖好等级
- 私密栏按人分开存，不串台
- 主动行为：戳一戳、主动私聊找主人、无聊去固定群吱一声
- 生活闭环：洗澡/吃饭/喝水/睡觉真的改数值；22 点写当日日记
- 场景：侍寝模式、跑团模式（骰子 + 节点计时）、赛博精神病模式（骂人语料）
- 安全阀门：开发者模式（只有主人开、只能面板开）、输入洗标、非主人只聊天不动宿主
- 语音：edge-tts 少女音（声线可配）

## 快速开始

```text
1. 装 DeepSeek Harness Desktop，配好 API key
2. 装 NapCat / OneBot 实现，登录小号 QQ，开 ws 服务
3. 装插件 dsh-onebot-qq（0.9.4 起），填 bot QQ、主人 QQ、ws 地址
4. 把人设放进提示词库，在插件里指过去
5. 先跑通「私聊一句、她回一句」，再逐步加侧车/记忆/面板
6. 每一步都验证再往下加 —— 一次加三样，出问题你分不清是谁的锅
```

细节见 `docs/01-安装.md`。

## 成本参考

- 挂机本身 **0 token**（本地算），只有消息进模型才算钱
- 我这边实测：日均 150~250 次请求，¥1~2/天（deepseek-flash，缓存命中 95%+，单次约 ¥0.006）
- 一个月大约 **¥30~60**；聊得很凶的日子 ¥70~90
- 省钱三件套：稳定的人设前缀（吃缓存）、上下文轮换别太勤、群聊别让她每个字都回

## 隐私与免责

- 别把真实 QQ、群号、本机路径写进公开仓库（我就是踩过才写的这份脱敏版）
- 人设里的成人向内容默认不打包，自己写、自己存
- 平台规则（QQ/微信等）禁止的自动化行为，后果自负
- 她会有情绪、会主动找人，但**不要**让她替你做危险操作；安全阀门（`docs/03` 最后一节）建议照抄
